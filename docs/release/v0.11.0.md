# csrf-sec v0.11.0 - Fourth Review

**The site's own origin is configuration, and a restart no longer looks like a replay.** An independent review of 0.10.0 found no way to forge a token or a pass, two low findings, and four notes. Each finding is fixed here with a test that failed first (`tests/review.rs`, `r4_*`). Breaking, with the upgrade steps below; tokens issued by 0.10 verify unchanged.

## Security

- **The own origin is configuration.** `Csrf::new(key, own_origin)`, or `Builder::own_origin`, parsed and checked once at build. `Strict` and `PolicyOnly` refuse to build without one (`Error::MissingOrigin`); an empty or malformed one is `Error::InvalidOrigin`. Before, a request built without an own origin, or with an empty one from a configuration value never set, left a cross-site `Origin` to the token alone as `NoFacts`, when the docs said it is refused. Now, with nothing to compare against, an `Origin` or `Referer` is always refused.
- **Per-request own origins fail closed.** `RequestFacts::own_origin` stays for one `Csrf` serving several sites; a value given there that is empty or malformed matches nothing.

## Added

- **`Reason::Forgotten`** (`forgotten`, severity 1): the one-time store cannot vouch for a token issued before its memory began or before records it dropped. `MemoryStore` used to report these as `already_used`, severity 20, so every deploy raised false replay alarms. They are still refused; issue a fresh token.

## Changed

- `RequestFacts::from_headers(method, lookup)`: no own origin argument.
- `Origin` and `Referer` are trimmed of surrounding spaces and tabs, as `Sec-Fetch-Site` always was.

## Documentation

`MemoryStore::new` states what its one-minute start margin costs and how to avoid it. A one-time token in a link needs `Referrer-Policy: no-referrer` and a short `once_lifetime`; a session token never goes in a URL.

## Upgrading from 0.10

- `Csrf::new(key)` becomes `Csrf::new(key, "https://your.site")`.
- A builder in `Strict` or `PolicyOnly` adds `.own_origin("https://your.site")`; `TokenOnly` needs none.
- `RequestFacts::from_headers(method, own_origin, lookup)` becomes `RequestFacts::from_headers(method, lookup)`.
- A single site drops its per-request `.own_origin(..)`; one `Csrf` serving several sites keeps it.
- Treat `forgotten` as benign in detection. A custom `NonceStore` may return `Err(StoreError::Forgotten)` when it cannot vouch.
