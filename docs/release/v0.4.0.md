# csrf-sec v0.4.0 - One-Time Tokens

**Single use for high-value actions, without giving attackers a lever on the store.** v0.4.0 adds one-time tokens: bind a form to a `NonceStore`, and its token passes exactly once.

```rust
let store = MemoryStore::new(100_000);
let pay = Binding::new(session_id).scope("POST /pay").once(&store);

let token = csrf.issue_with(&pay)?;        // 102 characters
csrf.verify_with(&pay, submitted)?;        // passes once; again: AlreadyUsed
```

## Highlights

- **The MAC comes before the store.** A one-time token is a signed token with a 128-bit random nonce inside the MAC. The MAC, the validity window, and the scope are checked first; only a token that passes all three asks the store to consume its nonce. A cross-site attacker submitting a wrong token with the victim's cookies cannot burn the victim's token, and forged requests never reach a shared store. A test with a spy store proves it: forged, wrong-session, wrong-scope, expired, future, foreign-key, and malformed tokens make zero `take` calls.
- **Exactly one winner.** Eight threads verifying the same token at once: exactly one passes, every round.
- **Fail closed.** A store that cannot record a nonce issues no token (`Error::Store`); a store that cannot answer refuses the request (`StoreUnavailable`). In every mode, including `PolicyOnly`, a one-time binding checks the token.
- **`MemoryStore`.** 64 shards behind their own locks, bounded and expiring. A full shard purges expired nonces and otherwise refuses to issue, rather than forgetting a token someone still holds. For a cluster, implement `NonceStore` over a store every node reaches.
- **Still allocation-free.** Issue, verify, and reuse of a one-time token with an allocation-free store make zero allocations, measured.
- **Format checked against its description.** A test rebuilds a version-2 token from the documented format with crypt-io directly and compares it byte for byte.

## Changed

- `NonceStore::insert` takes `now` as well as `expires_at`, so a bounded store can purge expired entries before refusing.
