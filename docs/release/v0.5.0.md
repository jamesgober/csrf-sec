# csrf-sec v0.5.0 - Feature Complete

**Every planned feature is in, every idea is decided, and the core runs on bare metal.** v0.5.0 closes the feature phase: ring introspection for clusters, a bare-metal `no_std` build in CI, recipes for the deployments people actually run, and a recorded decision for every idea on the list.

## Highlights

- **Key fingerprints for clusters.** `Csrf::keys()` lists the ring, signing key first, with each key's role and a public fingerprint; `Csrf::key_fingerprint(id)` returns one. A fingerprint is eight bytes of keyed BLAKE3 over a fixed label under the key's subkey: it reveals nothing about the key and cannot help forge a token, but every node holding the same key under the same id shows the same value. Compare them across nodes and a misdeployed ring is caught before it turns into a wave of `bad_mac` refusals.
- **Bare metal, proven in CI.** The core now builds for `thumbv7em-none-eabi`, a target with no standard library at all, on stable and 1.85, with and without `alloc`. A host build with `no_std` set could still pull in `std` through a dependency by accident; this target cannot.
- **Recipes.** `docs/API.md` shows how to protect a site with no server-side session (bind to a random `__Host-` cookie: signed double-submit with the cookie inside the MAC), revoke every token of a session without changing its id, keep tenants apart on one key ring, wire single-page applications through the `x-csrf-token` header, and what to log on a refusal. Every recipe is compiled as a test.
- **Every idea decided.** Adopted: key fingerprints and ring introspection, and detection guidance as documentation. Rejected, with the reason written down: a session-epoch field and an audience field (the existing bindings already do both), a custom-header fact and a simple-content-type fact (`Origin` and Fetch Metadata already cover every browser that preflights, and content-type gates have a history of bypasses), and a store-free replay filter (it is single use only on one node, which behind a load balancer silently means it is not).
- **Tier 3 example.** `examples/tier3.rs` uses only the `no_std` surface: explicit time, a caller-supplied randomness source, rotation, and fingerprints.

## What's next

`0.6.0` is the optimization phase: `criterion` benchmarks for issue, verify, the policy, and the codec; a comparison harness against the best existing Rust CSRF crates; and measured numbers replacing every estimate in the docs.
