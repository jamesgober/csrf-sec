# csrf-sec v0.10.0 - Simplicity

**One line for each common use, plain names, and one way to do each thing.** A pass over every public item before 1.0. Tokens, the request policy, and their security are unchanged; tokens issued by 0.9 verify unchanged. It breaks the API in small ways, listed under "Upgrading from 0.9".

## Added

- **`RequestFacts::from_headers(method, own_origin, lookup)`.** A request's facts in one call: the lookup returns a header by its lowercase name, and is asked for `sec-fetch-site`, `origin`, and `referer`. The shortest examples used to build the facts by hand and left out `Referer`, the fallback for browsers without Fetch Metadata.

  ```rust
  let facts = RequestFacts::from_headers("POST", "https://example.com", |name| headers.get(name));
  csrf.check(&facts, session_id, submitted)?;
  ```

- **`Csrf::generate_key()`** (feature `std`): a new key from the operating system's generator. Call it once, store the key, and load it at every start.

## Changed

- **`PadSource` is now `RandomSource`, and `OsPads` is now `OsRandom`**: the same trait and type, named for what they supply (the mask of every token and the nonce of a one-time token).

## Removed

- `RequestFacts::with_class`: `RequestFacts::new(method)` classifies the method.
- `FetchSite` from the public API: no public signature used it.
- `Token::len` and `Token::is_empty`: `Token` dereferences to `str`, so `token.len()` works unchanged.

## Upgrading from 0.9

- Rename `PadSource` to `RandomSource` and `OsPads` to `OsRandom`. Implementations keep the same `fill` method.
- `RequestFacts::with_class(MethodClass::classify(m))` becomes `RequestFacts::new(m)`.
- Code that named `FetchSite` passes the raw header value instead.
- Optional: use `RequestFacts::from_headers` in place of a chain of setters, and `Csrf::generate_key()` in place of a key made with the randomness trait.

## Checked

`docs/API.md` lists every public item: a script checked all 34 exported items and all 60 public functions against it. New tests cover `from_headers` (including a property test that it decides exactly as the setters do) and `generate_key`.
